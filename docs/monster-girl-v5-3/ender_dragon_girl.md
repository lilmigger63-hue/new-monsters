# Ender Dragon Girl — V5.3 stage1

Reference: inline image3 in the latest request. Existing registry ID `ender_dragon_girl` and server dimensions are retained. Original project artwork; no Gaia assets copied.

The five principal baseline differences were metallic rectangular eye frames, strip-like wings, flat fringe, a narrow chest opening and rigid-looking arm volumes. Pass1 replaces the eye stacks with readable lavender eyes and dark pupils, sweeps the fringe, introduces overlapping membrane bays and a broader pale opening framed by the dark yoke. Hair receives phase-offset cosmetic idle motion; wingtip fly/hover articulation is softened without changing clip duration, triggers or server flight physics.

Actual pass1 review found the wing ribs still visually dominant, thin horns resembling antennae, and the long overskirt obscuring the animated legs. Pass2 uses broad dark membrane surfaces with stepped edges, broader shorter gray horns and a shorter split overskirt. Pass3 closes the remaining pale forearm band with the original dark scale material. The original two-joint wing rig and three-joint tail remain intact.
