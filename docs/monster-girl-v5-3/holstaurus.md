# Holstaurus — V5.3 stage3

Reference: latest inline image16. Existing ID `holstaurus`; no entity replacement. Original project CC0 artwork. The prior actual1.3.0 all33 client evidence is reused as the baseline because the recorded initial hashes prove her assets unchanged; the two corrective runs are new focused client runs.

Five main baseline differences: helmet-like long slab hair, tall angular horns, armored-looking bare-arm volumes, striped metallic-looking boots and rigid tail tuft. Pass1 introduces a shorter layered lavender-gray bob, short ivory horns, muted inner cow ears, white halter details, hand-painted irregular cow markings and an articulated tail tuft. Atlas resolution stays128×128; more existing texels are allocated to visible boot patches instead of enlarging the image.

Actual pass1 review found that repainting the old arm plates still left armor-shaped shoulders and cuffs. Pass2 rebuilds the arms as connected tapered skin volumes, makes the leg marking UV density consistent and changes only the eye iris material to a muted gray-blue. Skin planes are painted with restrained shading. The waist bell retains its gold material. The original cow ears, white/gray body palette, waist silhouette and hopping behavior are preserved.

Validation: front/side/three-quarter/back/distant, horns and cow ears, facial features and bob, bare shoulder/elbow/wrist connections, cow-pattern boot faces, connected tail and tuft, attack/heavy/cast/hurt, walk/run, actual hop peak and landing, and grounded corpse inspected. Both focused runs pass; all35 asset/source/preservation checks pass. Attack/heavy/cast/hurt clips and the hop clip are unchanged; only idle/walk/run tuft secondary motion and geometry-based death support change. Both completed creatures, all20 originals, all gameplay/audio files and ten pending targets remain frozen unchanged.

Remaining differences: the cow patch layout, garment construction, haircut and unseen rear details are original interpretations. The supplied image does not show the tail; its established project design is retained with a small cosmetic articulation. Existing hopping gameplay remains, even though the reference is static. Still-frame sampling and software rendering do not certify every interpolation or physical GPU performance.

Final model: 22 bones / 112 cubes. Actual reviewed baseline plus 2 corrective client runs; each corrective run bakes/syncs all33 resource sets and presents one selected species.
