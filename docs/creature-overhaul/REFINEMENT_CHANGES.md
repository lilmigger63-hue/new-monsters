# Creature-by-creature refinement

Refinement of the existing 1.1.0-rc.1 designs. Geometry, materials and secondary motion are original work; [source access and license limitations](ASSET_ATTRIBUTION.md) prevented third-party integration. Main species palettes, equipment and gameplay are retained.

| Creature | Before → after | Cubes |
|---|---|---|
| Goblin Scout | Flat eyes/hands → layered face, curled gripping fingers, dagger pommel and stitched pouch/armor edges. | 40 → 64 |
| Goblin Shaman | Simple face and staff handle → readable eyes, gripping hand, wrapped handle and sewn robe/talisman edges. | 46 → 74 |
| Orc Warrior | Broad armor planes → stepped plate rims, defined eyes, shield bindings and finished cleaver grip. | 43 → 72 |
| Minotaur | Flat transitions → horn-root rings, muzzle lip, brass edges and gripping axe hand; bovine head retained. | 49 → 75 |
| Stone Troll | Eyes obscured by rock shell → forward eye planes, chiseled lids, knuckle/wrist strata and moss seams. | 58 → 80 |
| Ancient Treant | Abrupt wooden joints → overlapping bark, root knuckles, trunk knots and trailing crown motion. | 81 → 91 |
| Wild Wyvern | Flat wing membranes → wrist knuckles, membrane ribs and connected toes; two legs/two wings retained. | 82 → 106 |
| Dire Wolf | Box muzzle and hock joins → cheek/nose planes, connected paws, underfur shading and ear flicks. | 60 → 89 |
| Griffin | Straight beak and broad feathers → hooked beak, coverts, connected talons and restrained wing breathing. | 94 → 129 |
| Cave Basilisk | Broad snout/flanks → nostrils, mandible rim, cheek shields, scutes and counter-moving feet. | 46 → 73 |
| Frost Elemental | Abrupt ice joints → cheek/chin facets and layered joint planes; suspended core/nova timing retained. | 46 → 55 |
| Moon Stag | Bent hock swing → articulated flat cloven hooves and diagonal planted gait; antlers/saddle retained. | 71 → 81 |
| Forest Dryad | Bare face/leaves → expressive adult face, layered leaf hair, bodice/sash and lagging hair/vines. | 75 → 101 |
| Shadow Wraith | Blank hood interior → recessed adult spectral face, silver-blue hair and layered neckline/shroud motion. | 32 → 50 |
| Grave Knight | Closed bar visor → restrained adult face within armored recess, silver hair, plate lames and cape motion. | 44 → 75 |
| Slime Maiden | Square eyes/synchronized lobes → defined irises, gel fringe/palms and staggered lobe deformation. | 34 → 45 |
| Harpy | Simple face/crest → expressive face, swaying temple feathers, coverts and rear claw; wing-arms retained. | 59 → 73 |
| Demon Sorceress | Square face/flat hair → expressive face, angled fringe, collar/cuffs and palm finishing; horns/robe/sigils retained. | 80 → 94 |

Crystal Spider and Flame Imp are finished and remain byte-identical, including native sources and all texture variants/masks. All old bone IDs and clip names remain available across the 20 species. All 18 intended normal textures changed. Model complexity stays at or below 129 cubes.
