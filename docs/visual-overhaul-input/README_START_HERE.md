# New Monsters Visual Overhaul — Codex starter pack

1. Download this ZIP and extract it locally.
2. Clone/open `https://github.com/lilmigger63-hue/new-monsters` in Codex Desktop.
3. Attach or make the extracted `CODEX_MASTER_PROMPT.md` available to Codex; paste its entire contents as the job instruction. Place `reference/jar_inventory.json` somewhere Codex can read.
4. Optional: if you want Codex to inspect the original Forge JAR itself, attach your own `fossil-forge-1.20.1-9.3.4.0.jar` to that Codex project separately. The JAR is not in this ZIP, because it is third-party content and not a compatible mod dependency.
5. Ask Codex to execute changes in the cloned repository; this ZIP is a prompt/reference pack, not a pre-built mod or pre-generated completed character models.

**Sources**
- Repository: https://github.com/lilmigger63-hue/new-monsters
- Style inspiration: https://fossilsarcheology.wiki.gg/wiki/Mobs
- Attached local source examined: fossil-forge-1.20.1-9.3.4.0.jar (Forge 1.20.1). Geometry/animation inventory provided as metadata only.

**Compatibility**: the project uses Fabric 1.21.10, GeckoLib 5.3-alpha-3. Never install the Forge 1.20.1 reference JAR into this Fabric modpack.
