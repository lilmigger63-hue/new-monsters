# Mythic Realms: Creatures 1.4.0-rc.1

Fabric · Minecraft Java1.21.10 exactly · Java21 · Fabric Loader0.19.5+.

Original visual refinements for all thirteen expansion creatures, each reviewed individually in Minecraft. The twenty original creatures, sounds, gameplay, spawning and production renderer are preserved. All76 production classes are byte-identical to1.3.0-rc.1. Reference-inspired artwork is original project source; no Gaia artwork is included.
